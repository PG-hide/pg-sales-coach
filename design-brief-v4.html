01

素材棚卸し — 提供素材レビュー

ASSET INVENTORY

素材から確定する世界観

  • 主役色: PGブルー (#2563D9)、補助: イエロー / オレンジ / グリーン / パープル。明るく彩度高め

  • 表情6種は状態通知のリアクションに活用

パワプロ流のお作法を取り込む

  • 左サイドに担当者リスト(色分け)、上タブ + LR キーで切替
  • 担当者カードは黄色いネームタグ + 番号 + 顔写真 + 能力ランクのレイアウト
  • 能力はF/E/D/C/B/A/Sのランク文字 + 数値の併記
  • すべてのボタン・チップに黒縁 + 黒影。フラットだが立体的
  • 本文はNoto Sans JP Bold以上。数値はOutfit Black

QUESTIONS
Q1

v4.1の3カラム構成(顧客 / 案件 / スキル)で本質に合っていますか?

左=顧客管理、中央=案件対策(注力1案件 + 4ステップ + 1クリック実行)、右=スキルアップ。現行の「文字起こし入力 → 分析」というツール目線を、業務目線に再構成しました。中央の重み付け、各カラムの粒度の調整は可能です。

Q2

能力ランク(F/E/D/C/B/A/S)の項目は何にしますか?

パワプロ流に「弾道/ミート/パワー/走力/肩力/守備力/捕球」を営業に置き換える案。例: 提案幅 / 商談精度 / 大型案件対応 / 行動量 / レス速度 / 関係構築 / 引継ぎ。

Q3

サイドリストには全担当者を常時表示しますか?(部署内 / 自分のチームのみ)

マネージャー視点なら全員表示+検索が便利。担当者視点なら自部署のみが見やすい。両モードトグルも検討可能。

Q4

サブタブはどのカテゴリで分けますか?

仮置き「担当者データ / 活動能力 / 提案能力 / 関係構築・対応 / プロフィール」。実態に合わせて再分類します。

Q5

シールドのランク名は「F〜PGチャンピオン」をそのまま使いますか?

素材集の8段表記を採用しました。社内呼称があれば差し替えます。

Q6

本日の一手のロジックは?(AI / ルールベース / マネージャー手動)

初期はルールベース推奨。AIは過去案件データが整った段階で。

Q7

担当者写真の調達方法は?

PG社サイト転載 / 撮り下ろし / イラスト固定。Phase 02で本物を入れる前提なら、URLを2-3名分いただけると組み込めます。
